# Testing

Two suites: Vitest unit tests (`tests/unit/`) and Playwright e2e tests
(`tests/e2e/`, needs a running CMS instance).

## Unit Tests (Vitest)

```bash
npm run test:unit         # run once
npm run test:unit:watch   # watch mode
```

Config: `vitest.config.js` (environment `happy-dom`, globals on, spec glob
`tests/unit/**/*.spec.{js,ts}`). Setup file: `tests/unit/setup.js` — provides
global `$t`/`$tc` i18n mocks, `$route`/`$router` stubs, and global component
stubs (`FontAwesomeIcon`, `Loader`, `EmptyState`, `StatusBadge`, `FilterChip`,
`Dropdown`, `BasicButton`, `BasicInput`, `TextAreaBasic`, `FormField`).

`__client/` (per-deploy JSON configs) is generated by `scripts/init-client.js`
via the `preserve`/`prebuild`/`pretest:unit` npm hooks. The unit hook matters:
specs that import the real router pull in Builder views and their
`@/../__client/configs` imports, so the suite needs `__client/` to exist even
though most specs mock their stores and API clients.

### Spec layout

- `tests/unit/views/` — component tests, one subdirectory per panel
  (`Suppliers/`, `Pim/`, `Promo/`, `EnrichmentReview/`, …)
- `tests/unit/composables/` — composable unit tests
- `tests/unit/stores/` — store unit tests
- `tests/unit/router/` — router guard tests
- `tests/unit/boots/` — boot component tests

### Mocking the munin store

Views and router specs that touch panel/module gating mock
`@/stores/munin` directly with `vi.mock`, returning only the methods the
component under test needs:

```javascript
const mockIsPanelEnabled = vi.fn();
vi.mock("@/stores/munin", () => ({
  useMuninStore: () => ({ isPanelEnabled: mockIsPanelEnabled }),
}));
```

See `tests/unit/views/Suppliers/AutoMatched.spec.js`,
`tests/unit/views/Suppliers/Duplicates.spec.js`, and
`tests/unit/views/Suppliers/ProductsTab.spec.js` for the pattern.

Two specs cover module gating specifically:
- `tests/unit/views/Promo/PromoListVoucherGating.spec.js` — the Vouchers tab
  hides/shows based on `isModuleEnabled("checkout_voucher")`, including the
  locked `EmptyState` on a deep link without the module.
- `tests/unit/router/moduleGuard.spec.js` — the router `beforeEach` guard
  redirects `/promo/voucher/:pk` to the panel root when `meta.module` is
  unmet, and resolves normally when it is met. Mocks both `@/stores/munin`
  and `@/stores/user`.

## E2E Tests (Playwright)

```bash
npm test                    # build check + full e2e suite
npm run test:e2e            # full e2e suite only
npm run test:e2e:headed     # headed browser
npm run test:e2e:debug      # Playwright inspector
npm run test:e2e:ui         # Playwright UI mode
npm run test:smoke          # quick sanity (~2 min)
```

Helpers: `tests/helpers/auth.js` (`login(page)`, `logout(page)`),
`error-collector.js`, `suppliers-mock.js`, `suppliers-live-fixtures.js`.

## Writing Tests

Unit (Vitest + Vue Test Utils):

```javascript
import { describe, it, expect, vi } from "vitest";
import { mount } from "@vue/test-utils";

vi.mock("@/stores/munin", () => ({
  useMuninStore: () => ({ isPanelEnabled: () => true }),
}));

import MyView from "@/views/MyPanel/MyView.vue";

it("renders", () => {
  const wrapper = mount(MyView, { shallow: true });
  expect(wrapper.exists()).toBe(true);
});
```

E2E (Playwright):

```javascript
const { test, expect } = require('@playwright/test')
const { login } = require('../helpers/auth')

test('should do something', async ({ page }) => {
  await login(page)
  await page.goto('/route')
  await expect(page.locator('h1')).toContainText('Title')
})
```

Use `waitForLoadState('networkidle')` not `waitForTimeout`. Prefer
`text=Button` selectors.
